R toolkitKit de R

The R packages I use most for evidence synthesis, each with a short working example. These are community packages; the credit belongs to their authors, so please cite them.

Los paquetes de R que más uso para síntesis de evidencia, cada uno con un ejemplo breve que funciona. Son paquetes de la comunidad; el mérito es de sus autores, así que cítalos.

meta

Pairwise meta-analysis with sensible defaultsMetaanálisis por pares con valores por defecto sensatos
CRAN

My starting point for most reviews: binary, continuous and generic inverse-variance outcomes, forest and funnel plots, and prediction intervals.

Mi punto de partida en la mayoría de revisiones: desenlaces binarios, continuos y de varianza inversa genérica, forest y funnel plots, e intervalos de predicción.

install.packages("meta")
library(meta)

m <- metabin(event.e, n.e, event.c, n.c, studlab = study,
             data = dat, sm = "RR",
             method.tau = "REML",          # between-study variance
             method.random.ci = "HK",      # Hartung-Knapp CI
             prediction = TRUE)
summary(m)
forest(m, sortvar = TE)

metafor

The complete meta-analysis frameworkEl marco completo para metaanálisis
metafor-project.org

For meta-regression, multilevel models and anything the simpler interfaces do not cover.

Para metarregresión, modelos multinivel y todo lo que las interfaces más simples no cubren.

library(metafor)

es  <- escalc(measure = "SMD",
              m1i = m1, sd1i = sd1, n1i = n1,
              m2i = m2, sd2i = sd2, n2i = n2, data = dat)
res <- rma(yi, vi, data = es, method = "REML", test = "knha")
res
forest(res); funnel(res)
regtest(res)                       # Egger-type test (use with >= 10 studies)

netmeta

Network meta-analysisMetaanálisis en red
CRAN

Frequentist network meta-analysis with network graphs, league tables and treatment rankings.

Metaanálisis en red frecuentista, con grafos de la red, tablas de liga y rankings de tratamientos.

library(netmeta)

p  <- pairwise(treat = treatment, event = events, n = total,
               studlab = study, data = arms, sm = "OR")
nm <- netmeta(p, reference.group = "placebo")
netgraph(nm)
forest(nm)
netrank(nm)                        # P-scores

mada

Diagnostic test accuracy meta-analysisMetaanálisis de precisión diagnóstica
CRAN

Bivariate (Reitsma) model for sensitivity and specificity, with SROC curves.

Modelo bivariado (Reitsma) para sensibilidad y especificidad, con curvas SROC.

library(mada)

# dat needs columns TP, FN, FP, TN (one row per study)
fit <- reitsma(dat)
summary(fit)
plot(fit, sroclwd = 2, main = "SROC")
points(fpr(dat), sens(dat), pch = 2)
forest(madad(dat), type = "sens")

dmetar

Companion to Doing Meta-Analysis in RComplemento de Doing Meta-Analysis in R
GitHub

Helper functions for outlier detection and influence analysis on top of meta. Installed from GitHub.

Funciones auxiliares para detectar valores atípicos y analizar influencia sobre meta. Se instala desde GitHub.

install.packages("remotes")
remotes::install_github("MathiasHarrer/dmetar")
library(dmetar)

find.outliers(m)                   # m is a meta object
InfluenceAnalysis(m, random = TRUE)

estmeansd

Mean and SD from quantiles, for skewed dataMedia y DE desde cuantiles, para datos asimétricos
CRAN

Quantile-estimation (QE) and Box-Cox (BC) methods. Use it when the median-to-mean tool warns about skewness.

Métodos de estimación por cuantiles (QE) y Box-Cox (BC). Úsalo cuando la herramienta de mediana a media advierte asimetría.

library(estmeansd)

qe <- qe.mean.sd(q1.val = 31, med.val = 42, q3.val = 55, n = 64)
qe$est.mean
qe$est.sd
